### [1] [HSRAI: Permutation-Preserving Address Interleaving with Hierarchical Balance Metrics](https://arxiv.org/abs/2608.00016)
*Xiaotong Yuan*

Main category: cs.AR

TL;DR: 本文提出HSRAI地址交叉方法，通过保留高位与低位地址位、仅对中间索引段施加W位双射（GF(2)仿射映射或CRT变体），在多级互连拓扑中实现全局一一对应的地址映射，并同时满足各级出口端口的流量均匀性、设计期可接受性约束以及零长时间饥饿，解决了级联互连中传统随机刺激+终端均匀性验证不足的问题。


<details>
  <summary>Details</summary>
Motivation: 现有地址交叉交织方法仅以随机访问为激励、终端均匀性为验收标准，无法满足多级级联互连拓扑的要求。在级联结构中，映射必须是一对一且可逆的逻辑地址到编码地址的对应关系，同时需保证每一级出口端口的流量均匀，而不仅仅是终端从节点均匀。传统方法（如固定XOR、折叠/表）会在中间层级出现热点或长时间零访问，需要更严谨的全局双射设计与评估方法。

Result: 在128节点全域拓扑上，提出的仿射映射满足双射性、终端平衡、设计期可接受性阈值，以及高优先级接受集上的零长窗口饥饿。与固定XOR和折叠/表基线相比，HSRAI避免了中间级热点和扩展零访问期。在剪枝拓扑上，CRT变体在线性和平铺访问下显著改善了每级指标。

Conclusion: HSRAI通过地址段的精细划分与全局双射设计，为多级互连地址交叉提供了系统性解决方案，同时兼顾各级流量均匀性与长期访问公平性，并通过可复现的开源基准验证了其相对于传统基线的优势。

Abstract: Address interleaving balances bandwidth across caches, DRAM, and GPU partitions. In a multi-level interconnect topology, the mapping must be a one-to-one, invertible correspondence between logical and encoded addresses and, under typical access patterns, keep traffic uniform at every level's egress ports, not only at terminal slave nodes.
  Using random access as the stimulus and terminal uniformity as the acceptance criterion is insufficient for cascaded interconnects; this paper partitions workloads by access-pattern priority and requires a global bijection with no slave node left unvisited for extended periods. Per-level coefficient of variation (CV), consecutive same-port run length, and sliding-window peak occupancy evaluate traffic at each level's egress.
  HSRAI preserves high-order and intra-line low-order address bits and applies a W-bit bijection only to the intermediate index segment. Full-domain topologies use offline GF(2) affine search with matrix and salt parameters selected via priority-ranked access patterns and per-level admissibility hard constraints; pruned topologies combine the Chinese Remainder Theorem with remapping.
  Evaluation uses a reproducible C++ benchmark covering linear streams, matrix tiling, and 2D arithmetic lattices. On the 128-node full-domain topology, the proposed affine map satisfies bijection, terminal balance, design-time admissibility thresholds, and zero long-window starvation on the high-priority acceptance set; fixed XOR and folding/table baselines expose intermediate-level hotspots or extended zero-access periods. For pruned topologies, the CRT variant significantly improves per-level metrics on linear and tiling accesses. Artifact: https://github.com/xiaotongyuan/hsrai_address_hash (tag paper-v11).
