Motivation: 家庭独立学习常伴随不良坐姿、久坐时长过长、数字分心导致效率下降，且缺乏针对高难度自学内容的实时教学支架；现有方案多在成本、隐私（原始视频上云）与算力资源之间存在折中，缺少面向资源受限边缘设备的集成化解决路径。

Method: 硬件为 Raspberry Pi 3 Model B（1 GB RAM）+ UVC 摄像头 + USB 电容麦克风；端侧以 MediaPipe Pose 与 OpenCV 进行上半身对齐、矢状面头部倾角与冠状面肩部不对称的实时估计，不持久化原始视频流；用确定性有限状态机（FSM）量化有效学习时长、强制健康休息并检测违规手机使用；集成多模态 AI 辅导代理，经加密 API 网关解析语音/文本查询并生成苏格拉底式概念提示而非直接答案；轻量家长 Web 仪表盘提供加密的会话分析与排程配置。

Result: 物理原型基准：352×288 分辨率下端到端推理延迟 244–250 ms（4.0–4.1 FPS）；在 5,760 个合成真值姿态上躯干角度估计 MAE 为 4.39°；常驻内存集 320 MB；持续负载下 SoC 峰值温度 58.0°C；离线 TTS 反馈路径总延迟 1.58 s。

Conclusion: 结果表明该系统在资源受限边缘设备上具备较高实用性，可在低成本、隐私保护前提下同时实现人体工学监测、学习中段管理与 AI 教学辅助的集成部署；但精度与交互实时性受限于合成真值评估与低帧率，仍需真实数据与更大规模用户验证。

Abstract: During independent home study sessions, students frequently sustain improper sitting postures, accumulate excessive sedentary hours, and experience productivity loss from off-task digital distractions. Furthermore, learners often lack real-time pedagogical scaffolding for demanding self-study curricula. To mitigate these ergonomic and instructional challenges, this paper presents an affordable, privacy-preserving cyber-physical embedded system for domestic study spaces. Engineered on a Raspberry Pi 3 Model B (1 GB RAM) paired with a UVC optical camera and a USB condenser microphone, the system executes on-device computer vision utilizing MediaPipe Pose and OpenCV to monitor upper-body alignment, sagittal head inclination, and coronal shoulder asymmetry in real time without persisting raw video streams. A deterministic finite state machine (FSM) quantifies active study durations, enforces health-compliant rest periods, and detects illicit smartphone usage. Simultaneously, an integrated multimodal AI tutoring agent parses voice and text queries via an encrypted API gateway, synthesizing Socratic conceptual hints rather than direct solutions. A lightweight parental web dashboard delivers encrypted session analytics and scheduling configurations. Empirical benchmarks on the physical prototype confirm an end-to-end inference latency of 244-250 ms at a 352x288 resolution (4.0-4.1 FPS), a trunk-angle estimation error of 4.39 degrees MAE over 5,760 synthetic ground-truth poses, a resident set size of 320 MB, a peak SoC temperature of 58.0 degrees Celsius under sustained load, and a 1.58 s total latency for the offline TTS feedback path, proving high practicality for resource-constrained edge deployment.
