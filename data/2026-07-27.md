### [1] [HEMERA: A Heterogeneous Memory-Centric Accelerator with Recursive Dataflow for Edge-Constrained State-Space-Duality Models Inference](https://arxiv.org/abs/2607.22022)
*Hao Ding,Ling Liang,Ruitong Qiao,Dongxue Zhao,Xiantong Qiu,Jinshan Li,Meng Li,Lei Jin,Zhiliang Xia,Zongliang Huo,Zongwei Wang,Yimao Cai*

Main category: cs.AR

TL;DR: 针对Mamba-2模型中SSD计算范式带来的系统开销问题，本文提出HEMERA异构存储中心加速器，通过将其重构成等价的流式递归数据流，消除二次中间存储，在130M-2.8B模型上相比NVIDIA A100实现1.4x-3.6x加速和12.2x-27.0x能效提升。


<details>
  <summary>Details</summary>
Motivation: Mamba-2中的SSD计算虽然实现了线性复杂度，但其矩阵化执行方式引入了二次中间物化、不规则数据移动和前缀依赖执行等系统级开销，导致传统架构上内存流量和带宽需求过高。现有加速器未能同时避免二次中间存储和高效映射依赖传播。

Method: 将SSD矩阵形式计算重新表述为代数等价的流式递归数据流，消除二次中间存储并保留原始计算语义。采用异构执行范式：将稠密线性操作映射到存内计算单元，将递归状态更新映射到专用流式引擎。

Result: 在130M-2.8B Mamba-2模型上，平均延迟加速1.4x-3.6x，能效提升12.2x-27.0x（vs NVIDIA A100优化融合内核）；长序列推理中SSD执行时间占比降至14.12%。

Conclusion: HEMERA证明了异构存储中心架构在高效部署Mamba-2模型方面的潜力，特别适用于边缘设备上的长序列推理任务。

Abstract: Structured State Space Models (SSMs), such as Mamba, enable efficient long-sequence modeling with linear time complexity. Recent implementations realize this capability through Structured State Space Duality (SSD), which transforms recursive state evolution into matrix-form computations. However, SSD introduces substantial system-level overheads, including quadratic intermediate materialization, irregular data movement, and prefix-dependent execution, leading to excessive memory traffic and bandwidth demand on conventional architectures. Although prior accelerators mitigate these overheads through optimized dataflows or compute-in-memory techniques, they largely retain matrix-oriented SSD execution and cannot simultaneously avoid quadratic intermediate storage and efficiently map dependency-bound state propagation.
  This paper presents HEMERA, a heterogeneous memory-centric accelerator for efficient Mamba-2 inference. Rather than directly executing the matrix-form SSD computation, HEMERA reformulates it into an algebraically equivalent streaming-recursive dataflow that avoids quadratic intermediate storage while preserving the original computation. The resulting heterogeneous execution paradigm maps dense linear operations onto in-memory computing units and recursive state updates onto a dedicated streaming engine. Across Mamba-2 models ranging from 130M to 2.8B, HEMERA achieves average latency speedups of 1.4x-3.6x and energy-efficiency improvements of 12.2x-27.0x over the official optimized fused Mamba-2 kernel on NVIDIA A100. It further reduces the average SSD-related execution-time ratio across model scales to 14.12% during long-sequence inference, demonstrating its potential for efficient deployment under edge constraints.

### [2] [Sparse by Command: Task-Conditional Compute Skipping for Multi-Task Inference Accelerators](https://arxiv.org/abs/2607.22038)
*Afzal Ahmad,Gaoyu Mao,Shoubo Hu,Hui-Ling Zhen,Mingxuan Yuan,Xinyu Chen,Wei Zhang*

Main category: cs.AR

TL;DR: 本文提出了一种HW/SW协同设计方法，通过任务条件化门控网络预测每个tile的二进制执行掩码，在硬件层面跳过不必要计算，在FPGA原型上实现51-59%延迟降低和66-76% FLOPs减少，同时保持自动驾驶任务质量。


<details>
  <summary>Details</summary>
Motivation: 多任务推理模型共享同一骨干网络，但无论执行哪个任务都进行完全相同的计算，导致大量能量和周期浪费在与任务无关的操作上。任务指令在推理开始前即可获得，这是一个可以被利用的免费信号，但现有方法未能在硬件层面利用这一信号跳过不必要的计算。

Method: 1) 命令条件化训练：训练轻量级门控网络，联合骨干网络学习硬件对齐的tile级二进制掩码；2) 指令集架构扩展：每条指令携带per-tile位掩码字段，使硬件能直接跳过被掩码的tile；3) 硬件加速器设计：基于tile的推理加速器，支持可配置并行度、双缓冲存储器和INT8数据类型，原生支持稀疏tile执行。

Result: 在CARLA自动驾驶闭环视觉运动任务上，任务条件稀疏性减少FLOPs 66-76%，同时保持驾驶质量；FPGA原型上端到端延迟从9.12ms降至3.74-4.44ms（2.1-2.4倍加速），每次推理能耗从263mJ降至108-128mJ。

Conclusion: 所提出的HW/SW协同方法通过任务指令驱动tile级稀疏执行，在不改变模型架构或推理流程的前提下实现显著的计算减少和能效提升，验证了利用任务信息跳过无关计算的可行性。

Abstract: Multi-task inference models share a single backbone across diverse tasks, yet execute identical computation regardless of which task is active - wasting energy and cycles on task-irrelevant operations. We observe that the task command, typically available before inference begins, provides a free signal that can be exploited to skip unnecessary computation at the hardware level. We present a HW/SW co-designed approach in which a lightweight gating network, trained jointly with the backbone, predicts per-tile binary execution masks conditioned on the task input. Each tile corresponds to a fixed group of output channels (the native scheduling granularity of the accelerator), enabling masked tiles to be skipped with zero overhead. This yields a task-dependent reduction in compute, where each command activates only the subset of the network it requires, without changes to the model architecture or inference pipeline.
  We co-design the full system stack: a command-conditioned training procedure that learns hardware-aligned tile masks under a sparsity objective; an instruction set architecture whose instructions carry per-tile bitmask fields, allowing the hardware to skip masked tiles without software intervention; and a tiled inference accelerator with configurable parallelism, double-buffered memory, and INT8 datapath that natively supports sparse tile execution.
  We prototype on an AMD/Xilinx Alveo U50 FPGA and evaluate on a closed-loop visuomotor driving task in CARLA autonomous driving simulator. Task-conditional sparsity reduces FLOPs by 66-76% while maintaining driving quality. On-device latency decreases by 51-59%, from 9.12 ms to 3.74-4.44 ms (2.1-2.4x speedup), with energy per inference dropping from 263 to 108-128mJ.

### [3] [HiKV: Hierarchical Importance-Aware KV Cache with Hardware Acceleration for LLM Decoding](https://arxiv.org/abs/2607.22389)
*Chao Fang,Jun Yin,Man Shi,Marian Verhelst*

Main category: cs.AR

TL;DR: HiKV提出了一种算法-硬件协同设计方法，通过两阶段层级重要性感知策略（阶段I：驱逐不重要token；阶段II：仅加载保留token中的显著元素）压缩KV缓存，并设计了可重构重要性排序器的专用加速器，在注意力计算中实现最高7.95倍加速和90%能耗降低，精度损失仅1%。


<details>
  <summary>Details</summary>
Motivation: 长上下文大语言模型解码过程中KV缓存持续增长，成为关键的内存瓶颈。

Method: 算法层面：两粒度层级压缩——阶段I在固定预算内驱逐不重要token，阶段II仅加载保留token中的显著元素。硬件层面：设计以可重构重要性排序器为核心的专用加速器，统一两阶段加速。

Result: 在代表性LLM上，注意力计算实现最高7.95倍加速和90%能耗降低，精度损失仅1%；在同等精度下，外部内存访问额外减少1.82~4.87倍；硬件面积仅增加8%。

Conclusion: HiKV通过算法-硬件协同设计有效解决了长上下文LLM的KV缓存内存瓶颈问题，两阶段层级压缩策略优于单粒度方法，且硬件开销可控。

Abstract: With the rapid adoption of long-context large language models (LLMs), the continuously growing KV cache during decoding has become the critical memory bottleneck. To tackle this challenge, we propose HiKV, a novel algorithm-hardware co-design that exploits KV cache redundancy through hierarchical importance awareness. Algorithmically, HiKV compresses the KV cache at two granularities: Stage I evicts unimportant tokens within a fixed budget, and Stage II further loads only the significant elements of each retained token, reaching compression ratios unattainable at a single granularity. Architecturally, we develop a dedicated accelerator centered on a reconfigurable importance sorter that switches between the distinct sorting datapaths each stage requires, unifying the two-stage acceleration in one circuit with minimal overhead. Evaluated on representative LLMs, HiKV achieves up to 7.95x speedup and 90% energy reduction in the attention computation over the vanilla KV cache baseline within negligible 1% accuracy loss. Under iso-accuracy constraints, HiKV outperforms state-of-the-art importance-based methods by achieving an additional 1.82~4.87x reduction in external memory accesses. These benefits are enabled by specialized hardware components that add only 8% to the system area.

</details>
