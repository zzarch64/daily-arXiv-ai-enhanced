### [1] [Automated Pre-Silicon Verification of High-Speed DDR5 and LPDDR5/6 Memory Controllers: Closed-Loop Timing, Mode Register, and PHY Synchronization in UVM](https://arxiv.org/abs/2609.36111)
*Manan Patel,Anirban Majumder*

Main category: cs.AR

TL;DR: 本文提出一种面向内存控制器（Memory Controller）硅前验证的自动化配置与闭环初始化框架：通过解析DRAM VIP的JEDEC参数（如Denali SOMA文件）配置DUT寄存器，以自定义MR-RAL实时跟踪VIP的易变状态，并借助免重编译的PHY初始化流程在测试平台内随机化接口参数、动态生成配置并解析寄存器写序列。


<details>
  <summary>Details</summary>
Motivation: 外部存储器接口（LPDDR5/4、DDR5）是现代移动、云端与企业级计算的关键组成。由于多数半导体公司并非DRAM原厂，而是设计需搭配专用内存控制器以对接标准化外部存储器的定制ASIC，因此以第三方DRAM VIP为参照、对内存控制器RTL进行硅前设计验证，成为全行业普遍且关键的难题。传统验证流程中，手工配置寄存器、状态不同步导致的虚假协议违例以及PHY参数调整需反复重编译等问题，造成大量准备开销并限制测试覆盖。

Method: 1）参数自动解析：直接从DRAM VIP数据库文件（如Denali SOMA文件）中解析JEDEC时序与配置参数，用于自动配置内存控制器DUT寄存器。2）自定义MR-RAL：构建Mode Register Register Abstraction Layer，实时跟踪DRAM VIP中易变的模式寄存器状态，保持DUT与VIP状态一致。3）闭环PHY初始化：设计动态、免重编译的PHY初始化流程，在测试平台内直接随机化接口参数，通过系统调用即时生成配置，并在运行时解析生成的寄存器写序列，实现闭环初始化。

Result: 将上述自动化方法集成到硅前验证流程后，可消除环境搭建开销、避免因状态不同步产生的虚假协议违例，并支持对复杂PHY与内存控制器配置进行全面的随机化测试，从而提升验证效率与覆盖度。

Conclusion: 该框架以自动化参数解析、实时状态抽象与免重编译闭环初始化为核心，为内存控制器硅前验证提供了一套可复用的高效方法学，适用于需要对接LPDDR5/4、DDR5等标准化外部存储器的ASIC设计验证场景。

Abstract: External memory interfaces (such as LPDDR5/4 and DDR5) are essential components of modern mobile, cloud, and enterprise computing systems. While memory manufacturers focus on physical DRAM die development, the vast majority of semiconductor firms design custom application ASICs that require a dedicated Memory Controller to interface with these standardized external memories. Consequently, pre-silicon design verification of the Memory Controller RTL -- acting as the Device Under Test (DUT) against a third-party DRAM Verification IP (VIP) -- is a ubiquitous and critical challenge across the global semiconductor industry. This article presents an automated, pre-silicon configuration and closed-loop initialization framework for Memory Controller verification. The proposed solution parses JEDEC timing and configuration parameters directly from the DRAM VIP's database files (such as Denali SOMA files) to configure the Memory Controller DUT's registers, while a custom Mode Register Register Abstraction Layer (MR-RAL) tracks volatile DRAM VIP states in real-time. Furthermore, a dynamic, re-compilation-free PHY initialization flow randomizes interface parameters directly in the testbench, executes on-the-fly configuration generation via system calls, and parses the resulting register write sequences at runtime. By integrating these automated methodologies into pre-silicon verification flows, engineers can eliminate setup overhead, prevent false protocol violations, and enable comprehensive randomized testing of complex PHY and Memory Controller configurations.

### [2] [Lossless Compression of Lookup Tables for Hardware Applications](https://arxiv.org/abs/2609.36634)
*Alireza Khataei,Kia Bazargan*

Main category: cs.AR

TL;DR: 本文提出CompressedLUT，一种用于硬件中任意常量数据无损存储与检索的压缩方案及其解码器硬件架构，通过分解、自相似性、高位压缩与多级压缩技术最大化表大小节省，且在FPGA上实现非线性函数、常系数乘法器与KAN的12位分辨率评估，解码器以加法、算术右移和小型查找表为主，面积低、吞吐高，并开源。


<details>
  <summary>Details</summary>
Motivation: 硬件中广泛使用大型查找表存储常量数组（如常系数乘法、非线性函数评估、表基神经网络与KAN），但在FPGA等资源受限边缘设备上，存储大量常量表会造成过高的硬件开销，亟需无损压缩与高效检索方案。

Method: CompressedLUT结合分解、自相似性、高位压缩和多级压缩技术，在不损失精度的前提下最大化表大小节省；其硬件解码器主要使用加法、算术右移和若干小型查找表，以实现低面积和高吞吐。

Result: 在FPGA上以12位分辨率实现多种非线性函数、常系数乘法器（CCM）和KAN进行评估，验证了CompressedLUT的效果；该工具已作为开源工具发布。

Conclusion: CompressedLUT为硬件常量表提供了一种无损压缩及低开销、高吞吐解码器方案，适用于资源受限边缘设备中的多种数学运算与学习模型，并已开源供使用。

Abstract: Large lookup tables are widely used in hardware to store constant-valued arrays for applications ranging from elementary mathematical operations, such as constant-coefficient multiplication and nonlinear function evaluation, to emerging machine learning models, including table-based neural networks (NNs) and Kolmogorov-Arnold networks (KANs). However, storing extensive tables of constant values can lead to excessive hardware costs in resource-constrained edge devices such as FPGAs. In this paper, we propose CompressedLUT, a lossless compression scheme and its decoder hardware architecture for the efficient storage and retrieval of arbitrary data in hardware. Our method combines decomposition, self-similarities, higher-bit compression, and multilevel compression techniques to maximize table size savings without accuracy loss. Its hardware decoder primarily uses addition, arithmetic right shift, and several small lookup tables, ensuring low area and high throughput. We evaluated CompressedLUT on FPGAs by implementing multiple nonlinear functions, constant-coefficient multipliers (CCMs), and KANs at 12-bit resolution. CompressedLUT is available as an open-source tool.

### [3] [Low-level optimizations in high-level HDLs: Is there a benefit?](https://arxiv.org/abs/2609.37021)
*Oliver Keszocze,Tjark Petersen,Arved Friedemann,Matthias Bo Stuart*

Main category: cs.AR

TL;DR: 本文研究函数式编程在ASIC设计中的适用性，用函数式HDL Clash实现无符号位串行MAC单元的16种配置，对比高层抽象构造与底层优化对综合电路面积的影响，并与Verilog实现进行对照。


<details>
  <summary>Details</summary>
Motivation: 作者希望探究在ASIC设计中采用底层优化是否有益，以及其带来的实现开销是否值得；同时评估函数式高层抽象HDL特性相对于底层优化的实际效果，并考察HDL语言本身对电路面积的影响。

Method: 使用函数式HDL Clash实现无符号位串行乘累加（MAC）单元的16种不同配置，既采用底层位操作技术，也使用Clash的高层电路设计构造；为评估HDL本身的影响，还用Verilog实现了MAC的多个版本进行对比。

Result: 实验评估表明，Clash的部分高层构造对综合电路规模影响可忽略不计，说明充分发挥函数式编程能力是一种可行的硬件设计方法；但与资深工程师编写的Verilog代码相比，Clash似乎存在固有的面积开销。

Conclusion: 函数式高层抽象HDL可用于硬件设计且代价可控，但相对手写Verilog仍存在固有开销，使用底层优化是否值得需权衡实现投入与收益。

Abstract: This paper explores the applicability of functional programming to the design of Application-specific Integrated Circuits (ASICs). We investigate the impact of designing ASICs using high-level, abstract Hardware Description Language (HDL) features versus employing low-level optimizations on the area of the synthesized circuits. The aim is to determine whether using low-level optimizations is beneficial and, if so, whether it is worth the added implementation effort.
  To carry out the investigation, we implement an unsigned bit-serial multiply-accumulate (MAC) unit in 16 different configurations using the functional HDL Clash. We make use of both low-level bit-manipulation techniques as well as Clash's high-level constructs for circuit design. The experimental evaluation shows that some high-level constructs of Clash have negligible influence on the resulting circuit size, suggesting that using the full power of functional programming is a viable approach to hardware design. To evaluate the impact of the used HDL itself, we also implemented versions of the MAC in Verilog. The experiments clearly show that there seems to be an inherent overhead in using Clash compared to Verilog code written by a seasoned engineer.

### [4] [MEDEM: Multi-Engine DL Accelerator Design Methodology](https://arxiv.org/abs/2609.37399)
*Fareed Qararyah,Mohammad Ali Maleki,Pedro Trancoso*

Main category: cs.AR

TL;DR: 本文提出多引擎深度学习加速器设计方法学MEDEM，通过通用引擎抽象、引擎协同设计与组合选择，高效探索指数级设计空间，在51个DL工作负载上实现最高4.84x EDP和1.59x吞吐量提升。


<details>
  <summary>Details</summary>
Motivation: 现代DL工作负载具有异构性和日益增长的复杂性，多引擎DL加速器成为趋势。但现有多引擎加速器设计方法缺乏系统性方法学，两个基本问题未解决：如何针对具有不同计算特征的工作负载协同设计引擎，以及哪种引擎组合能在这些工作负载上最小化总执行成本（时间或能耗）。解决这些问题需要高效探索指数级大的设计空间。

Method: 提出MEDEM（Multi-Engine DL Accelerator Design Methodology）。MEDEM定义通用引擎抽象，协同设计候选实例（引擎），并在给定多样化DL工作负载和资源预算下，选择一组协同设计的引擎组合以最小化总执行成本。MEDEM包含一组设计策略，可高效地在引擎协同设计和组合选择的指数级设计空间中导航，识别高度优化的多引擎加速器。

Result: 综合评估表明，MEDEM识别出的加速器优于当前最先进设计，在能量延迟积（EDP）上最高实现4.84x的几何平均提升，吞吐量提升1.59x。这些提升在不同资源预算下均能实现，验证了MEDEM的可扩展性；在51个单模型和多模型DL工作负载上得到验证，体现了其通用性。

Conclusion: MEDEM为多引擎DL加速器设计提供了系统性方法学，通过通用引擎抽象与高效设计空间探索策略，解决了引擎协同设计和组合选择两大基本问题，在多种资源预算和广泛工作负载下均展现出优于SOTA的性能、可扩展性和通用性。

Abstract: Multi-engine deep learning (DL) accelerators are becoming increasingly prevalent as they address the heterogeneity and growing complexity of modern DL workloads. To efficiently process diverse DL workloads, these accelerators must incorporate combinations of engines with complementary capabilities to match the distinct computational characteristics of these workloads' heterogeneous kernels. However, existing multi-engine DL accelerator design approaches lack a systematic methodology, leaving fundamental questions unresolved. These include how to co-design engines for workloads with diverse computational characteristics and which engine combinations minimize aggregate execution costs (such as time or energy) across such workloads. Addressing these questions requires efficient exploration of exponentially large design spaces.
  To address these questions systematically, this work proposes Multi-Engine DL Accelerator Design Methodology (MEDEM). MEDEM defines generic engine abstractions, co-designs candidate instances (engines), and selects a combination of co-designed engines to minimize aggregate execution cost given diverse DL workloads and a resource budget. MEDEM encompasses a set of design strategies that efficiently navigate the exponentially large design spaces of engine co-design and combination selection, identifying highly optimized multi-engine accelerators. A comprehensive evaluation demonstrates that MEDEM identifies accelerators that outperform state-of-the-art designs, delivering geometric-mean improvements of up to 4.84x in energy-delay product (EDP) and 1.59x in throughput. The improvements are achieved using different resource budgets, demonstrating MEDEM's scalability, and using 51 single- and multi-model DL workloads, demonstrating its generalizability.

### [5] [Zephyr: An Efficient Audio Denoising System Using Spiking Neural Networks Enabled With A Sparsity-Aware Flexible FPGA PE Array](https://arxiv.org/abs/2609.37711)

We then propose a digital circuit which by means of a sparsity-aware flexible PE array can perform inference of the heterogeneous compute load of Spiking-FullSubNet, and validate this circuit on a PYNQ-Z1 FPGA achieving a real-time factor of 0.727 at 100MHz.
