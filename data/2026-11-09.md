### [1] [RoadBlock: Rethinking GPU Tensor Core Microarchitecture for Emerging Microscaling Format Support](https://arxiv.org/abs/2611.08526)
*Nikhil Rout,Blaise Tine*

Main category: cs.AR

TL;DR: RoadBlock 是一个基于 RISC-V Vortex GPGPU 的开源框架，用于在可编程 Tensor Core 中对自定义 MX 格式进行准确的端到端建模，暴露数据位宽、缩放因子位宽与块大小等可配置参数，并自动推导任意格式的每线程元数据分块，从而在流片前完成格式特定的 Perplexity-PPA 权衡评估。


<details>
  <summary>Details</summary>
Motivation: 近期多种自定义 Microscaling（MX）格式提案在模型质量上优于 OCP MX，但其硬件评估仅停留在独立 MAC 单元原型层面，忽略了在真实 GPU Tensor Core 内部集成时的系统级开销，导致评估不完整、难以支撑流片决策。

Method: 构建开源框架 RoadBlock，搭建于 RISC-V Vortex GPGPU 之上，实现可编程 Tensor Core 中自定义 MX 格式的端到端精确建模；将数据位宽、缩放因子位宽、块大小参数化，并自动推导任意格式下的每线程元数据分块方案。

Result: 支持对任意自定义 MX 格式进行格式特定的 Perplexity-PPA（模型困惑度—功耗/性能/面积）权衡评估，且评估覆盖系统级集成开销，而非仅限 MAC 单元原型。

Conclusion: RoadBlock 为自定义 MX 格式提供了可在流片前使用的端到端系统级评估手段，弥补了现有工作缺失的 GPU Tensor Core 集成开销建模环节。

Abstract: While multiple recent custom Microscaling (MX) format proposals preserve higher model quality over OCP MX, their hardware evaluations remain confined to standalone MAC-unit prototypes, ignoring the system-level integration overheads inside real GPU Tensor Cores. To this end, we present RoadBlock, an open-source framework for accurate end-to-end modeling of custom MX formats in a programmable Tensor Core, built on the RISC-V Vortex GPGPU. RoadBlock exposes data size, scale-factor size, and block size as configurable parameters and automatically derives per-thread metadata tiling for arbitrary formats, enabling format-specific Perplexity-PPA tradeoff evaluation before silicon commitment.

### [2] [SAFTAC: Simulation-Augmented Fine-Tuning of Open-Source LLMs for Analog Circuit Design](https://arxiv.org/abs/2611.08543)
*Junsheng Huang,Yifan Sun,Zhuoer Zhang,Ning Wei,Yening Liu,Michael Molter,Pavan Kumar Hanumolu,Elyse Rosenbaum,Bin Hu,Huan Zhang*

Main category: cs.AR

TL;DR: 该文构建了8,626个任务、覆盖10类模拟电路、以仿真为依据的大规模数据集，并提出SAFTAC框架，将三阶段监督微调与仿真反馈增强的强化微调结合，训练LLM端到端地按规格生成并修正模拟电路设计。


<details>
  <summary>Details</summary>
Motivation: 模拟IC设计中电路拓扑、器件尺寸与性能紧密耦合，设计难度高。现有基于LLM的方法存在两类不足：一是围绕冻结模型做推理期纠错，二是仅在有限电路类型上训练且未把仿真结果直接作为训练信号。核心瓶颈在于缺乏能支撑LLM端到端、以规格为条件设计训练的数据集。

Method: 首先构建以仿真为依据的大规模数据集：8,626个设计任务、10类模拟电路，每个任务含文本描述、标注I/O端口、负载条件、目标规格、testbench与参考网表。在此基础上提出SAFTAC微调框架：一是三阶段监督微调，逐步建立模拟电路设计与反馈引导纠错能力；二是仿真反馈增强的强化微调，以仿真结果构成的奖励进一步优化模型。

Result: 在单次生成与带仿真反馈的两次生成两种设定下评测，SAFTAC分别相较最强闭源LLM提升15.9%与7.8%。

Conclusion: 仿真依据的数据集与仿真反馈驱动的监督+强化联合微调能有效提升LLM的规格条件下模拟电路设计能力，验证了将仿真结果作为训练信号的价值。

Abstract: Circuit design for analog integrated circuits (ICs) is challenging because circuit topology, device sizing, and circuit performance are tightly coupled. Existing large language model (LLM)-based methods either rely on inference-time correction around frozen models or train on limited circuit types without directly using simulation outcomes as training signals. A key bottleneck is that existing datasets do not provide sufficient task information for training LLMs on end-to-end specification-conditioned design. To fill this gap, we first construct a large-scale simulation-grounded dataset with 8,626 design tasks across 10 different types of analog circuits, where each task includes a textual description, labeled I/O ports, loading condition, target specifications, a testbench, and a reference netlist. Using this dataset, we present SAFTAC, a simulation-augmented fine-tuning framework that trains LLMs to generate and revise analog circuit design. SAFTAC combines three-stage supervised fine-tuning, which progressively builds the capabilities required for analog circuit design and feedback-guided correction, with simulation feedback-augmented reinforcement fine-tuning, which further optimizes models using simulation-grounded rewards. We evaluate SAFTAC under single-pass generation and two-pass generation with simulation feedback, showing improvements over the strongest closed-source LLM by 15.9% and 7.8%, respectively.

### [3] [Enabling Retraining-Free Accurate Inference in Analog Compute in Memory Accelerators](https://arxiv.org/abs/2611.08693)
*George Karfakis,Puneet Gupta*

Main category: cs.AR

TL;DR: 提出免重训练、低成本共享校准的方法，通过输入中心化与模拟阵列定制的Hadamard旋转改变层的片上表示，使预训练模型可直接在简单模拟CIM阵列上高精度推理。


<details>
  <summary>Details</summary>
Motivation: 模拟CIM虽能消除权重搬运、显著提升推理能效，但转换器与器件误差使预训练模型无法直接使用，而硬件感知重训练代价高昂。

Method: 关键观察是模拟误差取决于各层在阵列上的表示方式，且该表示可离线改变而不改变计算本身。据此对输入做中心化，并施加为模拟阵列设计的Hadamard旋转，使共享参考误差保持分散，并将输入混合限制在单个阵列内部。

Result: 在CNN、ViT及最高14B参数的LLM上、于PCM与ReRAM平台验证：视觉模型与较大LLM的精度与浮点差距缩小至数个百分点，且在不训练任何权重的情况下达到或接近已发表硬件感知训练的效果。6-bit ADC的ReRAM上，ViT-B/16由37.4%恢复至82.9%，Phi-4由27.0%恢复至72.2%，均在浮点精度2.2个百分点以内。

Conclusion: 通过离线改变阵列表示（中心化+定制Hadamard旋转）即可实现免重训练的模拟CIM高精度推理，兼容多种网络与器件，效果可与硬件感知训练相当。

Abstract: Analog compute-in-memory (CIM) accelerators compute matrix-vector products directly inside memory arrays, eliminating weight movement and promising order-of-magnitude gains in inference efficiency. However, converter and device errors make pretrained models unusable on these arrays, and hardware-aware retraining is costly. We enable retraining-free, accurate inference of pretrained models on simple analog arrays with low-cost, shared calibration. Our key observation is that analog error depends on how each layer is represented on the array, and that this representation can be changed offline without changing the computation. We center the inputs and apply Hadamard rotations designed for analog arrays, which keep shared reference errors spread and confine input mixing to each array. Across CNNs, vision transformers and LLMs up to 14B parameters on PCM and ReRAM, the method brings vision models and larger LLMs within a few points of floating-point accuracy and matches or approaches published hardware-aware training without training any weights. On ReRAM with 6-bit ADCs, it restores ViT-B/16 from 37.4% to 82.9% and Phi-4 from 27.0% to 72.2%, both within 2.2 points of floating-point accuracy.

### [4] [TwinHash: Two-Sided Object Identity Management for Time- and Energy-Efficient Agentic Workflows](https://arxiv.org/abs/2611.09254)
*Sangbu Yun,Jung Gyu Min,Jin Hyun,Jeonghwan Ahn,Youngjoo Lee*

Main category: cs.AR

TL;DR: TwinHash 提出统一的对象管理架构，融合输入侧哈希键、输出侧内容指纹、类型特定复用守卫与软硬件对象表，将 agentic 工作流中的结构性冗余转化为服务效率收益。


<details>
  <summary>Details</summary>
Motivation: Agentic AI 服务将 LLM 生成与外部工具执行交织，并依赖反复回访共享推理状态的搜索式工作流，导致工具输出、LLM 响应与 KV 前缀存在大量冗余。现有服务系统只优化共享 prompt 前缀，而以输入为键的朴素缓存又因相同请求可能产生不同输出而不安全。

Method: TwinHash 为每个对象分配输入侧哈希键以识别重复请求，分配输出侧内容指纹以校验并定位已存状态，并辅以类型特定的复用守卫保证正确性与响应多样性。软件对象身份表跨请求与轨迹维护可复用对象；硬件对象放置表在分层内存中跟踪驻留状态，使被驱逐状态可被取回而非重算。

Result: 在 7 个 agent 框架与 5 个基准套件上，复用模式更多取决于工作流结构而非基准本身。TwinHash 在确定性工具读取重现时可服务多达 81% 的工具输出，在搜索式框架中可服务多达 92% 的 LLM 响应；从 DRAM 取回被驱逐 KV 前缀使 Qwen3-32B 上 TTFT 降低最多 5.6 倍，更大稠密模型收益预计更高；搜索式框架下端到端实际耗时降低最多 87%，任务能耗降低最多 81%（相对前缀缓存基线），并以每键服务上限调节自适应搜索中的质量—复用权衡。

Conclusion: 统一的身份、安全与放置管理可将新兴 agentic 工作流中的结构性冗余转化为显著的服务效率提升。

Abstract: Agentic artificial intelligence (AI) services interleave large language model (LLM) generation with external tool execution, and increasingly rely on search-based workflows that repeatedly revisit shared reasoning states and computations. These patterns create substantial redundancy across tool outputs, LLM responses, and key-value (KV) prefixes, yet existing serving systems primarily optimize shared prompt prefixes, while naive input-keyed caching is unsafe when identical requests produce different outputs. We present TwinHash, a unified object management architecture that assigns each object an input-side hash key to recognize repeated requests and an output-side content fingerprint to validate and locate stored state, complemented by type-specific reuse guards that preserve correctness and response diversity. A software object identity table maintains reusable objects across requests and trajectories, while a hardware object placement table tracks their residency across hierarchical memory tiers so that evicted state can be retrieved rather than recomputed. Across seven agent frameworks and five benchmark suites, reuse follows workflow structure more than benchmark identity. TwinHash serves up to 81% of tool outputs wherever deterministic tool reads recur, and up to 92% of LLM responses in search-based frameworks. Retrieving an evicted KV-prefix from DRAM reduces TTFT by up to 5.6x on Qwen3-32B, with greater gains projected for larger dense models. Under search-based frameworks, TwinHash reduces end-to-end wall-clock time by up to 87% and measured task energy by up to 81% over a prefix-cached baseline, while a per-key serving cap controls the quality-reuse trade-off in adaptive search. These results demonstrate that unified identity, safety, and placement management can convert structural redundancy in emerging agentic workflows into substantial serving-efficiency gains.

### [5] [Memory as a Temporal Resource: Lifetime Contracts for Multi-Retention Systems](https://arxiv.org/abs/2611.09518)
*Adrian Jackson*

Main category: cs.AR

TL;DR: 论文主张将"数据保留期（lifetime）"提升为一等系统资源，跨算法、编程系统、控制器与器件协同管理，并提出基于事件的有效性契约，将应用完成事件与保留类选择及保护续期绑定，配合面向短暂/纪元/持久三类的同质存储阵列，通过裕量、ECC、刷新、迁移或重计算保证正确性，并给出基于trace的模拟器与FPGA原型。


<details>
  <summary>Details</summary>
Motivation: 现有存储系统把数据保留时长当作固定的物理属性加以隐藏，而实际数据有用寿命跨越内层循环迭代到数年不等，这种"一刀切"的保留策略造成不必要的开销与低效；作者认为应让必需寿命成为跨层次的显式资源。

Method: 在既有寿命感知放置（lifetime-aware placement）工作基础上，提出事件驱动的有效性契约：应用可声明"直到该tile完成"等语义契约，系统据此选择保留类别并续期保护；数据映射到为短暂（ephemeral）、纪元（epoch）、持久（durable）保留而设计的同质阵列；正确性通过裕量、ECC、刷新、迁移或重计算等机制维持。实现上采用基于trace的模拟器与支持类别迁移的FPGA原型进行验证。

Result: 构建了trace驱动的模拟器与FPGA原型，并演示了保留类之间的数据迁移机制；摘要未给出定量性能、能耗或可靠性数据。

Conclusion: 数据保留时长应作为一等资源在算法、编程系统、控制器与器件各层统一表达与管理；基于事件的有效性契约与多保留类同质阵列是可落地的实现路径，模拟器与FPGA原型初步验证了类迁移的可行性。

Abstract: Computers move and rewrite data whose useful lifetimes range from inner-loop iterations to years, yet memory systems usually hide retention as a fixed physical property. We argue that required lifetime should become a first-class resource across algorithms, programming systems, controllers, and devices. Building on prior lifetime-aware placement, we propose an event-based validity contract that links application completion events to retention-class selection and renewal of protection. Applications would be enabled to express semantic contracts such as ``until this tile completes'' and the system will map data to homogeneous arrays engineered for ephemeral, epoch, or durable retention and preserve correctness through margins, ECC, refresh, migration, or recomputation. We present a trace-based simulator and FPGA prototype that exercises class migration.

</details>
